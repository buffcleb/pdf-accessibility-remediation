# Settings reference

[Operations](README.md) › Settings reference

Every setting the service reads from its environment, with its default and what it does. [Configuration](configuration.md) is the overview: where settings live and the ones most often changed. What super admins change in the app (branding, limits, retention, services, AI levels) is in the [super admin guide](../user-guide/super-admins/settings.md).

> This page is generated by `scripts/settings_reference.py` from the code: don't edit it by hand. A setting's description is kept where the setting is defined (the docstring under it in `app/config.py` or `portal/config.py`, its comment in `deploy/k8s/deploy.env.example`, or the script's tables for the rest). Change it there and run `python scripts/settings_reference.py`; a test fails when the two differ.

Secrets never show a value: their default says *generated* (`scripts/deploy.sh init` makes one) or *set when used*.
