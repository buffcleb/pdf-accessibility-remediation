# Reporting a problem, and tips for checking

[The tag manager](README.md) › Reporting a problem, and tips for checking

## Reporting a problem

**Report a problem**, at the top right, opens the help form about the document, with the version and page filled in.
With a tag selected it reads **Report a problem here** and fills in the tag as well. **Report a problem with this
tag** in the tag menu does the same. See [Getting help](../getting-help.md).

## Tips for checking

- **Figures:** read the alt text against the image. Does it say what the image is *for*? A chart's description should
  give the trend or the key values, not just "a bar chart". See [Figures](figures.md).
- **Headings:** do they form a sensible outline? A heading should introduce a section, not just be bold text. The tag
  tree shows the outline: each section with its heading.
- **Reading order:** switch **Show** to *Reading order* on multi-column pages, pages with sidebars and pages with
  figures, and check the numbers run the way a person would read. See [Reading order](reading-order.md).
- **Lists and tables:** a list read as one paragraph, or a table read as text, can be rebuilt. See [Lists and tables
  of contents](lists-and-contents.md) and [Tables](tables.md).
- **Math and notation:** read the read-aloud text of formulas marked as written by AI; the AI can confuse similar
  symbols.
- **Listen:** [Read aloud](read-aloud.md) catches order and alt-text problems quickly, but check with a real screen
  reader before you finish.
