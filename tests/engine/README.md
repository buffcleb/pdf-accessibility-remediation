# Engine tests

Every test file of the engine suite (`app/`): what it checks, what it needs beyond Python, and the to-dos (GitHub
issues) and pull requests it belongs to. How to set up and run the suites as a whole: [../README.md](../README.md).

## Running them

From the repository root, with the `.venv` set up:

| To run | Command |
|---|---|
| The whole suite, side by side | `.venv/bin/python -m pytest -q -n auto tests/engine` |
| One file | `.venv/bin/python -m pytest -q tests/engine/test_adobe.py` |
| One test | `.venv/bin/python -m pytest -q tests/engine/test_adobe.py::test_expired_token_is_refreshed` |
| Tests whose names match words | `.venv/bin/python -m pytest -q tests/engine -k "table and header"` |
| With print output and the reason for each skip | add `-s -rs` |

**Needs** says what a file needs beyond Python. Without it, the tests that need it are skipped (`-rs` says which),
and the rest of the file still runs. The engine image has all of it except `shasum`; see
[../README.md](../README.md#the-tests-that-need-system-tools).

**To-dos** are the GitHub issues the test or the PR that added it names; "(open)" marks one still open. **PRs** are
the pull request that added the file and the most recent ones that changed it; `git log --follow` on the file has
the whole history.
